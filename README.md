# CompoundingTools

**Real questions. Helpful answers. Better decisions.**

Free educational calculators. **Your Information. Your Decision.**

## Launch
The static website is in `index.html`. GitHub Actions deploys it to GitHub Pages when Pages is configured with **Source: GitHub Actions** under **Settings → Pages**. A repository owner must enable this setting if it is not already enabled.

Expected Pages address after a successful deployment:
https://chaosbegone365-create.github.io/compoundingtools/

## Product priorities
1. Am I Underpaid? (requires authoritative, properly licensed wage benchmarks)
2. Wealth by Age (Federal Reserve dataset, cohort and coverage disclosures)
3. One-Income Family (tax and benefits assumptions)
4. Coast FIRE (inflation and withdrawal assumptions)
5. Vacation Budget Builder (estimated vs live pricing clearly separated)

## Business objectives
- March 2027 stretch target: $2,000 monthly gross revenue, not guaranteed.
- $0 recurring software cost target within free-tier limits.
- Human, appealing, helpful, profitable, hands-off, easy to return to, and SEO-driven.
- Financial and medical high-stakes material must pass elevated review.
