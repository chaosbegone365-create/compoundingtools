Privacy Policy

Last updated: October 25, 2026.

The current Compound Your Future calculators run directly in your browser. The website does not currently provide user accounts or a server-side calculator submission system. Calculator inputs are not intentionally transmitted to Compound Your Future servers.

GitHub Pages and underlying network providers may process technical request information, such as IP addresses, for delivery and security. External fonts or images may also result in requests to third-party providers.

The suggestion link currently opens GitHub Issues. Information submitted there is handled by GitHub and may be publicly visible. Do not submit sensitive personal information.

No advertising or payment processing is currently integrated. If analytics, advertising, accounts, or payments are introduced, this notice must be updated before activation.

For project-related privacy questions, use the repository's GitHub Issues channel without including confidential information.
