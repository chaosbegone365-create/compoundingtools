## Next priorities

1. Verify the released corrections in the live browser, including invalid inputs and repeated interactions; record exact release and deployment evidence.
2. Expand the core investment-growth, retirement, compensation and mortgage tools with original worked examples, assumptions, interpretations, source links and accessible result tables. Keep calculations consistent with disclosed compounding and contribution timing.
3. Replace generic category descriptions with specific guidance and useful related-tool links. Improve the existing tools before creating more pages.
4. Harden remaining simple forms against empty/non-finite input and add explicit edge-case tests. Native required-field validation is not a substitute for computation validation.
5. Add a documented calculator acceptance checklist and measured mobile/keyboard/performance checks. Structured data must describe visible, accurate content; do not fabricate reviews or expertise.
6. Configure Search Console only with owner authorization and the correct property. Analytics must be privacy-conscious and must not transmit calculator inputs. Until access is verified, impressions, queries, clicks, CTR, position and engagement remain unavailable.
7. Review priorities weekly and actual search performance monthly when available. Never promise rankings or revenue.

## Constraints

Preserve GitHub Pages, domain email, premium design, existing URLs and AdSense verification. No recurring software costs. No paid tools, bought links, mass near-duplicate content, invented credentials, or financial/medical advice claims. Do not publish a real-price benchmark comparison until source access, coverage, adjustment basis and permitted use are verified.
